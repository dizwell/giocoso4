Giocoso Version 4 is a gapless, trackless, optionally-randomising command-line FLAC player, intended primarily for the playback of digital classical music, on macOS, Windows and Linux. It is licensed under the GPLv2. It uses a MariaDB database back end to store details about what recordings are available to play; and to generate selections of music to begin playing. See https://bbritten.com/giocoso4/manual for full documentation and installation steps.
